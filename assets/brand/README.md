# Kendr brand asset

`kendr-mark-ink-512.png` is the canonical Kendr mark used by this repository.
It is a 512 x 512 transparent PNG supplied by Kendr for project identification.

The mark uses Kendr Ink `#151412` and Saffron `#E2712A`. On dark surfaces it
must sit on Kendr Paper `#FAF8F4`. Keep clear space equal to 25% of the mark
width on every side. Do not recolor, rotate, add gradients, or add shadows.

The organization name is **Kendr**. `Kendr-AI` may still appear inside GitHub
URLs because it is the repository-owner slug, not the public organization name.

or mark in a way that suggests sponsorship, certification, or endorsement.
